# BGH PhoneBook (Wails v2 Desktop App)

ระบบสมุดโทรศัพท์ภายใน โรงพยาบาลบ้านแพ้ว (Banphaeo General Hospital Internal Directory)
พัฒนาด้วย **Wails v2** (Go + Vue 3 + TypeScript + SQLite) ทำงานเป็น **Windows Desktop GUI Application** โดยตรง ไม่ต้องเปิดเว็บเบราว์เซอร์แยก

---

## สถาปัตยกรรมระบบ (Architecture)
- **GUI Framework**: [Wails v2](https://wails.io) (ผสาน Go Backend เข้ากับ Microsoft WebView2 ให้เป็น Native Windows App)
- **Frontend**: Vue 3 + TypeScript + Vite + SheetJS (`xlsx`)
- **Backend / IPC**: Go 1.25 (Wails Runtime + Pure Go SQLite `modernc.org/sqlite` ไม่ต้องใช้ CGO)
- **Database**: SQLite ในตัว (ไฟล์ `data/phonebook.db` จัดเก็บข้างไฟล์ EXE)
- **Typography**: Google Sarabun (ธีมทางการและทันสมัยสำหรับโรงพยาบาล)

---

## ฟังก์ชันการทำงาน
- 🖥️ **Windows Desktop Native Window**: เปิดเป็นหน้าต่างโปรแกรม Windows GUI โดยตรง พร้อมไอคอนประจำแอป
- 🔍 **ระบบค้นหาศูนย์กลาง Super Omni-Search (ออกแบบสำหรับ IT & เจ้าหน้าที่โดยเฉพาะ)**:
  - วางเด่นตรงกลางแบบ Hero Centerpiece พร้อมคีย์ลัดกด <kbd>Ctrl+K</kbd> หรือ <kbd>/</kbd> เพื่อโฟกัสค้นหาทันที
  - ค้นหาเจอทุกอย่าง: ชื่อหน่วยงาน, เบอร์ภายใน (เช่น 1041, 1111), เบอร์ตรง/สายนอก, ตึก, ชั้น หรือค้นหาหลายคำพร้อมกัน
  - ระบบตัดขีด/ช่องว่างในเบอร์โทรศัพท์อัตโนมัติ (พิมพ์ `034419555` หรือ `034-419555` ก็เจอ)
  - สลับขอบเขตการค้นหาได้ทันที: `[🌐 ทุกตึก (ทั้ง รพ.)]` (ค้นหาเจอทุกตึกแน่นอน) หรือ `[🏢 เฉพาะตึกที่เลือก]`
  - ไฮไลท์คำค้นหาแบบ Realtime บนทุกตึกและทุกชั้น พร้อมแถบสรุปจำนวนผลลัพธ์และปุ่มล้างคำค้นหาในคลิกเดียว
- 📋 **คัดลอกเบอร์โทรด่วน แยกปุ่มอัตโนมัติ (Multi-Number Quick Copy)**:
  - หากหน่วยงานมีหลายเบอร์ (คั่นด้วยจุลภาค `,`, ทับ `/`, หรือเซมิโคลอน `;` เช่น `9508 , 1062` หรือ `9590 / 1041 , 1079`) ระบบจะแยกออกเป็นปุ่มกดอิสระแต่ละเบอร์ทันที
  - สามารถคลิกเลือกคัดลอกเฉพาะเบอร์ที่ต้องการได้โดยตรง (คัดลอกเฉพาะตัวเลขที่กด ไม่ติดเครื่องหมายคั่นหรือเบอร์อื่น) พร้อมสถานะแจ้งเตือนแยกตามเบอร์
  - รองรับทั้งเบอร์ภายในและเบอร์สายนอก ทั้งในมุมมองการ์ดและตาราง
- 🏢 **จัดกลุ่มข้อมูลและฟิลเตอร์**: แสดงผลตาม ตึก → ชั้น → การ์ดหน่วยงาน พร้อมระบบกรองดู "🏢 ทั้งหมด" หรือเลือกเฉพาะชั้นที่ต้องการ
- 📍 **ระบบย้ายสถานที่หน่วยงาน (Department Relocation)**:
  - **ย้ายรายหน่วยงาน**: มีปุ่มลัดรูปหมุด `📍` บนทุกการ์ดและทุกแถวในตาราง สามารถเลือกตึกและชั้นปลายทางใหม่ได้ทันที
  - **ย้ายหลายหน่วยงานพร้อมกัน (Bulk Relocate)**: มี Checkbox ติ๊กเลือกหลายหน่วยงาน แล้วกดย้ายสถานที่ทั้งหมดไปยังตึก/ชั้นเป้าหมายใหม่ในคลิกเดียว เหมาะสำหรับกรณีปรับปรุงอาคารหรือย้ายโซนบริการ
  - **รองรับตึกและชั้นใหม่**: สามารถเลือกจากรายชื่อตึก/ชั้นเดิม หรือพิมพ์สร้างตึกและชั้นใหม่ได้โดยตรง
- ✏️ **จัดการข้อมูล CRUD**: เพิ่ม, แก้ไข และลบข้อมูลหน่วยงานได้ทันที
- 📊 **นำเข้า / ส่งออก Excel (.xlsx / .csv)**:
  - ส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx) ที่จัดรูปแบบคอลัมน์สวยงาม
  - นำเข้าข้อมูลด้วย Drag & Drop พร้อมระบบตรวจสอบความถูกต้อง (Validation) และดูตัวอย่างข้อมูล (Preview Table) ก่อนบันทึก
  - เลือกระหว่าง **เพิ่มต่อท้าย (Append)** หรือ **เขียนทับทั้งหมด (Replace / Restore)**
  - มีปุ่มดาวน์โหลดไฟล์ตัวอย่าง Template (.xlsx)
- 💾 **สำรองและพิมพ์**:
  - สำรองข้อมูลเป็นไฟล์ JSON
  - โหมดพิมพ์รายงานสมุดโทรศัพท์ (`Ctrl+P` / ปุ่มพิมพ์) ที่ซ่อนเมนูและจัดหน้าสำหรับเครื่องพิมพ์โดยเฉพาะ
- 🌱 **Seed ข้อมูลอัตโนมัติ**: สร้างฐานข้อมูลและนำเข้าข้อมูลเริ่มต้น 268 รายการโดยอัตโนมัติในครั้งแรกที่เปิดโปรแกรม

## การเปิดใช้งานโปรแกรม (Production)
เพียงดับเบิลคลิกเปิดไฟล์:
👉 **`BGH-PhoneBook.exe`**

* โปรแกรมจะเปิดขึ้นมาเป็นหน้าต่าง Desktop Application ทันที
* ข้อมูลจะถูกจัดเก็บในโฟลเดอร์ `data\phonebook.db` ข้างไฟล์ EXE
* เครื่องผู้ใช้งานปลายทาง **ไม่ต้องติดตั้ง Node.js, Go หรือเครื่องมือใดๆ เพิ่มเติม** (Windows 10 / 11 มี WebView2 มากับระบบอยู่แล้ว)

---

## การ Build โปรแกรม (Build as Windows EXE)
(สำหรับเครื่องที่มี Node.js, Go และ Wails CLI ติดตั้งไว้)

1. ดับเบิลคลิก **`build.bat`** (หรือรันคำสั่ง `wails build`)
2. ระบบจะทำการ Compile Frontend และ Go Backend ให้เป็นไฟล์ **`BGH-PhoneBook.exe`**

---

## โหมดพัฒนา (Development Mode)
ดับเบิลคลิก **`run-dev.bat`** (หรือรันคำสั่ง `wails dev` ใน Terminal)
* Wails จะเปิดหน้าต่างโปรแกรมพร้อมเปิด Hot-Reloading สำหรับทั้ง Vue 3 Frontend และ Go Backend ให้โดยอัตโนมัติ

---

## โครงสร้างโปรเจกต์
```
BGH-PhoneBook/
├── build/                # ไฟล์ Windows manifest, ไอคอนแอป (.ico, .png)
├── data/                 # ไฟล์ฐานข้อมูล SQLite (phonebook.db)

│   │   ├── components/   # EntryModal.vue, ImportModal.vue
│   │   ├── services/     # api.ts (Wails IPC + Web fallback), excel.ts
│   │   ├── App.vue
│   │   ├── style.css
│   │   └── types.ts

├── app.go                # Go Business Logic & Wails Bindings
├── main.go               # Wails Application Entrypoint & Window Configuration
├── seed.json             # ข้อมูลเริ่มต้น 268 รายการสำหรับ Seed ครั้งแรก
├── wails.json            # การตั้งค่า Wails Project

├── run-dev.bat           # สคริปต์รันโหมด dev
└── BGH-PhoneBook.exe     # ไฟล์แอปพลิเคชัน Windows พร้อมใช้งาน
```
